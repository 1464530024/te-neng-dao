IMA 知识库导出
通过 IMA 官方开放接口，把整个知识库按目录结构导出为本地 Markdown 与原始文件（图片自动下载，附件原样保留）。

到 ima.qq.com/agent-interface 登录后生成 Client ID 与 API Key，填入下方即可（一次配置长期有效）。

插件中心
安装 Chrome 扩展增强解析能力，或为特定网站配置自定义解析规则。
浏览器扩展
支持三种安装方式：① 已解压的扩展文件夹；② .crx 文件；③ .zip 压缩包。扩展会加载到抓取会话中，用于增强网页解析与登录辅助。
自定义解析规则
遇到小网站、内部知识库等自动识别不理想时，用规则指定「正文容器选择器」即可精准提取。选择器写法：右键网页元素 → 检查 → 复制 selector。
