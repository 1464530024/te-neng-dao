## 一、安装

### 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，64 位 |
| 内存 | 建议 4GB 以上 |
| 磁盘 | 安装约 450MB，另需空间存放导出文件 |
| 网络 | 需要联网（抓取网页内容必须联网） |

### 安装步骤

1. 拿到安装包 `特能导-1.4.0-安装包.exe`（约 100–150MB）。
2. **双击运行**。若 Windows 弹出「已保护你的电脑」蓝色提示，点 **更多信息 → 仍要运行**。
   - 这是因为安装包没有购买微软的数字签名证书，属于常见情况，不影响使用。
3. 选择安装位置（默认装在当前用户目录下，**无需管理员权限**）。
4. 勾选「创建桌面快捷方式」，点 **安装**。
5. 安装完成后会自动启动。桌面和开始菜单都会出现「特能导」图标。

> **提示**：安装范围为「仅为我安装」，不会修改系统目录，也不需要管理员权限。若想装到 `C:\Program Files`，请右键安装包选择「以管理员身份运行」。

## 二、3 分钟上手

### 第 1 步：复制链接

在浏览器、微信、手机上复制你想导出的内容链接。**一次可以复制多条**。

### 第 2 步：粘贴并选格式

打开特能导 → 左侧「**链接导出**」。

链接输入区是**一行一条**的独立输入框：

- 粘贴一条链接后，它会**固定在这一行**（还能继续编辑），右侧显示该链接的**类型简称**（公众号 / IMA / 知乎 / 压缩包 / 文档…）
- 粘贴完成的**同时会自动新增下一个空输入框**，等你粘下一条
- 一次粘贴多条？会自动拆成多行分别落位
- 输错了点右侧 `×` 删除，回车跳到下一行

然后勾选想要的格式（**PDF / Markdown / Word / HTML / TXT / JSON / CSV 清单**，可多选）。

### 第 3 步：开始导出

点蓝色大按钮「**开始导出**」。任务进入后台队列自动执行。

此时你可以：
- 继续粘贴新的链接提交新任务（支持多任务同时进行）
- 切换到「内置浏览器」浏览网页
- 做别的事情

任务完成后，**屏幕右下角会弹出提醒**（带醒目标记 + 文字说明），点击提醒可直接定位到文件。

## 三、七类来源怎么导

### 1. 微信公众号

**做法**：直接粘贴 `https://mp.weixin.qq.com/s/xxxxx` 链接，无需登录。

保留内容：标题、公众号名称、发布时间、正文排版、图片（含动图）、代码块。
> 图片会完整下载并内嵌，导出后离线也能看。

### 2. IMA 知识库导出（独立功能区）

**左侧导航「IMA 知识库」是一个独立功能区**，与「链接导出」在入口、界面、操作流程上完全分开。它通过 IMA 官方开放接口，把整个知识库**按目录结构**导出为本地 Markdown 与原始文件。

**输出结构**（与开源工具 wandao 一致）：

```
导出根目录/
  知识库名/
    文件夹A/
      笔记1.md
      笔记1_assets/
        image-001.png
      子文件夹/
        笔记2.md
    文件B.pdf
```

**四步操作**：

1. **接口凭据** —— 到 `ima.qq.com/agent-interface` 登录后生成 Client ID 与 API Key，填入「① 接口凭据」，点「保存凭据」或「测试连接」（一次配置长期有效）。
   > 直接用粘贴即可；程序会自动清理 Windows 记事本可能带入的 BOM 字符。
2. **选择知识库** —— 点「读取知识库列表」，在下拉框选择要导出的知识库。
3. **读取目录并勾选** —— 点「读取目录」，稍等片刻会列出完整目录树；勾选想导出的文档（可用「全选 / 全不选」）。
4. **导出** —— 选择导出根目录，点「开始导出」。页面实时显示进度，完成后点「打开导出目录」。

**它会做什么**：

1. 逐层拉取目录树，**完整保留多层嵌套结构**
2. 笔记正文直接取 Markdown 原稿，**图片自动下载**到 `文档名_assets/` 目录并按 `image-001.png` 命名，正文里改写为相对引用
3. PDF / Word / 压缩包等附件**原样保存**；同名文件自动加 `_2`、`_3` 序号不覆盖
4. 默认「按知识库名自动创建子文件夹」，去掉勾选则直接导出到所选根目录

> 未配置接口凭据时不会报错，只是无法使用本页面。若你只是想抓某个网页，可改用「链接导出」。

#### 网页深抓（通用兜底）

「链接导出」页仍保留通用的**知识库目录深度抓取**能力：把 IMA 分享链接粘贴进去并勾选「知识库目录深度抓取」，即可递归展开左侧目录树、逐篇抓取并合并为一份带目录的文档。它无需任何配置，但保真度与速度不如「IMA 知识库」的开放接口方式。

**做法**：
1. 先到「内置浏览器」打开 `https://ima.qq.com/`，用微信扫码登录（只需一次）。
2. 打开你要导出的知识库分享链接，复制地址栏网址。
3. 回到「链接导出」粘贴，**确保勾选「知识库目录深度抓取」**。
4. 开始导出。

> 如果抓到的文档数为 0，通常是：① 还没登录；② 分享链接本身不含可读文件；③ 该知识库的目录不是常见的树形结构。可以先用「内置浏览器」打开该链接点「解析此页」，看预览里能否列出目录。

### 3. 直接下载压缩包 / 文档（不做网页解析）

**链接本身就是一份文件时**（`.zip` / `.rar` / `.7z` / `.pdf` / `.docx` / `.xlsx` / `.pptx` / `.epub` / `.exe` 等），
特能导会**直接把它下载下来**，而不是当成网页去解析正文。

**做法**：把文件链接粘贴进来 → 右侧会显示「压缩包 · ZIP」或「文档 · PDF」这类标签 → 开始导出。

- 文件会原样保存到 `<导出目录>\直接下载\`
- 中文文件名会正确保留
- 大文件采用**流式下载**，不会占用大量内存
- 压缩包里的内容如需展开，下载后自行解压即可

> 这条通道和「资源嗅探」配合使用效果最好：先用嗅探把页面上的文档链接全找出来，再挑需要的下载。

### 4. 小红书

**做法**：
1. 先到「内置浏览器」打开 `https://www.xiaohongshu.com/` 登录。
2. 打开目标笔记，复制链接。
3. 粘贴到「链接导出」开始导出。
4. 若失败，改用「内置浏览器」打开笔记 → 点右上角「**解析此页**」。

保留内容：笔记标题、正文、作者、全部图片（图集会依次排列）。

### 5. 知乎

**做法**：知乎对未登录访问限制较严，**建议先在内置浏览器登录**。
- 问答页会自动展开全部回答
- 专栏文章保留标题层级与代码块

### 6. 新闻网站

已内置正文识别规则的站点（**无需登录，直接粘贴即可**）：

澎湃新闻、新华网、人民网、央视网、中新网、环球网、观察者网、财新、第一财经、证券时报、
网易、腾讯、新浪、搜狐、今日头条、百家号、界面新闻、36氪、IT之家、cnBeta、极客公园、凤凰网 等。

### 7. 其它任意网站

直接粘贴即可，软件会启用智能正文识别（自动找出正文区域）。

**如果识别效果不理想**，到「插件中心 → 自定义解析规则」为该网站指定正文选择器：

1. 在浏览器中打开该网页
2. 右键正文区域 → **检查**
3. 在右侧元素面板中右键对应的 DOM 节点 → **Copy → Copy selector**
4. 把复制到的选择器粘贴进规则里保存

之后该网站的导出就会精准命中正文。

## 四、导出格式说明

| 格式 | 适合场景 | 说明 |
| --- | --- | --- |
| **PDF** | 存档、打印、发给别人 | 版式与网页一致，图片内嵌，单文件可直接查看 |
| **Markdown** | 二次编辑、导入知识库系统 | 纯文本结构化；图片同时存到同名的 `.assets` 文件夹，用相对路径引用 |
| **Word** | 需要继续编辑的文档 | 标准 `.docx`，保留标题层级、表格、图片 |
| **HTML** | 长期归档 | 带样式的单文件网页，图片已内嵌，双击用浏览器打开 |
| **TXT** | 只要文字 | 纯文本正文，体积最小、任何设备都能打开 |
| **JSON** | 喂给 AI / 接入知识库系统 | 结构化数据：标题、作者、发布时间、大纲、正文，多文档时按篇拆分 |
| **CSV 清单** | 用 Excel 做后续加工 | 多篇文档的标题、**层级路径**、字数、来源汇总成一张表 |

> 导出知识库时建议勾上 **CSV 清单 + JSON**：前者方便在 Excel 里核对抓了哪些文件，后者带完整层级路径与正文，可以直接投喂给你自己的检索系统。

### 关于「层级路径」

从知识库（如 IMA）导出时，每篇文档都会记录它在目录树中的位置，例如
`产品资料/产品需求/需求文档v1`。这个路径会体现在 CSV 的「层级路径」列、JSON 的 `path` 字段，
以及 TXT 每篇文档标题下方，方便你还原原有目录结构。

**关于文件命名**：默认用文章标题作文件名，可在「设置 → 文件名模板」自定义，支持变量：

| 变量 | 含义 |
| --- | --- |
| `{title}` | 标题 |
| `{platform}` | 平台名（微信公众号 / 知乎 / 小红书…） |
| `{author}` | 作者 |
| `{date}` | 导出日期，如 2026-10-27 |
| `{time}` | 导出时间戳 |
| `{host}` | 网站域名 |

**关于存放位置**：默认导出到 `下载\特能导导出`，并自动按平台建子文件夹。
可在「设置 → 默认导出文件夹」或链接导出页的「选择文件夹」中修改（支持每个任务单独指定）。

## 五、任务中心

提交任务后会**自动跳转到任务中心**，你能立刻看到进度。

**这里保存全部任务**（进行中 + 已完成），并按日期分组：

```
今天  (3)
  ├ 微信公众号 · 12 条      已完成
  ├ 直接下载 · 4 条         已完成
  └ 混合平台 · 5 条         进行中
昨天  (2)
  ...
2026-10-24  (1)
```

**每个任务可以**：

- **实时进度条**：显示 已完成/总数，深抓知识库时还会显示 `深抓 3/27　文档名`
- **详情**：展开看到每条链接的状态、失败原因、生成的文件（可直接点击打开）
- **取消**：正在执行的任务可随时取消
- **重试失败项**：只重跑失败的那几条，成功的不会重复导出
- **打开目录 / 定位文件**：直接跳到导出结果
- **移除**：从列表里清掉（不影响已导出的文件）

**关掉软件也不怕**：任务记录会自动存到本地，下次打开应用仍在。
上次没跑完的任务会标成「**已中断**」，点「重试失败项」即可继续。

> **多任务**：任务之间并行执行。默认同时跑 3 个任务，可在「设置 → 同时执行的任务数」调整。
> 建议不要超过 4，过高容易触发网站风控。

## 六、内置浏览器（强烈推荐）

这是特能导最稳的抓取方式，**适用于所有需要登录或内容靠脚本动态渲染的网站**。

### 6.1 基本用法

1. 左侧点「内置浏览器」——**默认自动打开百度首页**
2. 像正常浏览器一样操作：搜索、登录、翻页、展开评论
3. 打开目标文章后，点右上角蓝色按钮「**解析此页**」
4. 右侧弹出预览抽屉，确认内容无误后点「导出这份内容」

### 6.2 地址栏：既能开网址，也能搜索

地址栏支持两种输入，自动判断：

| 你输入的内容 | 会发生什么 |
| --- | --- |
| `mp.weixin.qq.com` 或 `https://xxx.com/a/1` | 直接打开该网址（可省略 `https://`） |
| `考研英语怎么复习` | 用你设置的搜索引擎搜索 |

搜索引擎可在「设置 → 内置浏览器」中切换：**百度（默认）/ 必应 / 搜狗 / 360 / Google / 知乎 / 哔哩哔哩 / 微信搜索**，也支持完全自定义（用 `%s` 代表关键词）。

同一处还能改**默认打开网址**（默认 `https://www.baidu.com/`），或从「常用站点」下拉里一键选（IMA 知识库、公众号、知乎、小红书、澎湃新闻…），也可以关掉「进入时自动打开默认网址」。

### 6.3 点击链接不会弹窗

在页面里点搜索结果、`target="_blank"` 的外链，**都会直接在这个内置浏览器里打开**，不会弹出新窗口。

### 6.4 资源嗅探（按需开启）

用来批量抓取页面上的图片、文档、压缩包等资源。

**操作**：

1. 打开目标网页
2. 点工具栏上的「**嗅探**」按钮（默认关闭，**必须手动点才开始**）
3. 按钮变红显示「嗅探中」，右侧滑出资源面板
4. 浏览或滚动页面，新出现的资源会**实时加入列表**
5. 勾选需要的资源（或点「全选」），点「**下载选中**」

**页面上的文件链接也能被识别**：无论是绝对路径还是相对路径（`/files/报告.pdf`、`docs/合同.docx`），只要页面里存在指向文件的链接，嗅探都会把它们列出来 —— 即使你还没点击过它们。

**收集范围**：

| 会收集 | 不收集 |
| --- | --- |
| 图片（png / jpg / gif / webp / svg / ico / avif…） | ❌ **视频**（mp4 / m3u8 / webm / mov…） |
| 文档（pdf / doc(x) / xls(x) / ppt(x) / txt / md / csv / epub…） | ❌ **音频**（mp3 / m4a / wav / flac…） |
| 压缩包（zip / rar / 7z / tar / gz…） | ❌ 网页自身的 html / css / js 与字体 |
| 其他文件（exe / apk / psd / srt / 字幕…） | |

**面板功能**：

- 顶部分类筛选：图片 / 文档 / 压缩包 / 文件，点一下即可只看某一类
- 每项显示缩略图（图片）、文件名、类型、大小
- 悬停出现「复制链接」和「用系统浏览器打开」
- 右上角 `↻` 重新扫描当前页面已有资源，`🗑` 清空列表，`✕` 收起面板
- 底部的文件夹图标可指定保存位置

**保存位置**：默认 `<你的导出目录>\嗅探资源\<日期>\`。

> 小技巧：如果页面内容是滚动懒加载的，先点嗅探，再把页面往下滚一遍，最后点右上角 `↻` 重新扫描，能拿到的资源最全。

**常用站点**：页面中间提供了快捷入口（百度、IMA 知识库、微信公众号、知乎、小红书）。

## 七、历史记录

每一次导出都会留下记录：

- 按**标题、作者、平台、链接**搜索
- 按平台筛选
- 一键打开 PDF / Word / Markdown / HTML 文件
- 打开所在文件夹、回到原文链接
- 导出全部记录为 **CSV 表格**（可用 Excel 打开）
- 删除单条记录或清空全部

> 清空历史记录**不会**删除已经导出到磁盘的文件。

## 八、插件中心

### 8.1 浏览器扩展

可以让抓取会话加载 Chrome 扩展（例如阅读模式、翻译、内容增强类扩展）。

**安装方式**（三选一）：

| 来源 | 说明 |
| --- | --- |
| 扩展文件夹 | 已解压的扩展目录（内含 `manifest.json`） |
| `.crx` 文件 | Chrome 商店下载的扩展包 |
| `.zip` 文件 | 打包成 zip 的扩展 |

**操作**：插件中心 → 「安装扩展」→ 选择文件或文件夹 → 自动加载。

**注意事项**：

- 应用内会存一份扩展副本，你原始目录中的文件不会被改动，之后移动/删除原目录也不影响。
- 「启用 / 禁用」的变更需要**重启软件**后生效；「卸载」立即生效。
- 部分扩展使用了 Electron 尚未支持的高级能力，可能加载失败并给出提示，属正常现象。

### 8.2 自定义解析规则

用于解决小众网站、企业内部知识库的正文识别问题。

填写项：

- **域名匹配**：如 `kb.example.com`，也支持 `*.example.com`
- **正文容器选择器**：最关键的一项，可填多个（每行一个，按顺序尝试）
- **需要删除的元素**：可选，如 `.ad-banner`、`.recommend-list`
- **标题 / 作者 / 时间选择器**：可选，用于补齐元信息

## 十、常见问题

**Q1：提示「该页面需要登录」怎么办？**
到「内置浏览器」打开同一网址完成登录，然后回到该页点右上角「解析此页」。登录状态会长期保留。

**Q2：提示「站点触发了风控验证」怎么办？**
在内置浏览器中打开该页，手动完成滑动/人机验证，再用「解析此页」提取。

**Q3：导出成功但图片没下载下来？**
导出结果里会明确提示「有 N 张图片未能下载，已保留原始链接」。常见原因是图片受登录态或防盗链保护。可先在内置浏览器登录该平台后重试。

**Q4：能同时跑多少个任务？**
默认 3 个并行。可在设置里调整，但过高容易触发目标网站风控，建议不超过 4。

**Q5：导出的 PDF 里中文显示正常吗？**
正常。PDF 由内置浏览器引擎直接渲染打印，使用的是系统中文字体，不会乱码。

**Q6：Markdown 的图片为什么是个文件夹？**
Markdown 是纯文本格式，无法把图片塞进文件里。所以图片会统一存放在同名的 `.assets` 文件夹中，`.md` 文件用相对路径引用。**移动文件时请把 `.md` 和 `.assets` 文件夹一起移动**。

**Q7：安装时提示「已保护你的电脑」/ 杀毒软件报警？**
因为安装包没有商业代码签名证书。选择「更多信息 → 仍要运行」即可。若企业杀软拦截，请让 IT 加白名单。

**Q8：可以装到别的电脑上吗？**
可以。把安装包发给对方，双击安装即可，无需其他依赖。

**Q9：支持 Mac / Linux 吗？**
当前版本仅提供 Windows 64 位安装包。

**Q10：能批量导出一个公众号的全部历史文章吗？**
可以。在「链接导出」中把多篇文章链接一起粘贴（每行一条），一次提交即可。

**Q11：内置浏览器的默认首页怎么改？**
设置 → 内置浏览器 → 「默认打开网址」，填网址或用右侧「常用站点」下拉一键选，例如填 `https://ima.qq.com/` 就能让内置浏览器每次直接进 IMA。

**Q12：地址栏输入中文会搜索还是当网址？**
含空格或不像域名的内容（如「考研英语怎么复习」）会走搜索；像 `baidu.com`、`mp.weixin.qq.com` 这种会直接打开。

**Q13：嗅探会抓到视频吗？**
不会。程序在类型和扩展名两层做了过滤，`mp4 / m3u8 / mp3 / m4a / flac` 等一律不收，只保留图片、文档、压缩包和其他文件。

**Q14：为什么点了嗅探，列表里只有几张图？**
嗅探只记录**点击之后**新发生的网络请求。想拿全，做法是：先点嗅探 → 把页面往下滚动一遍触发懒加载 → 点面板右上角 `↻` 重新扫描当前页面已有资源。

**Q15：嗅探的资源存到哪了？**
默认存到 `<导出目录>\嗅探资源\<日期>\`。也可以点面板底部的文件夹图标单独指定位置。下载完成的提醒点一下即可打开该文件夹。

## 十二、卸载

### 方式一：通过 Windows 设置

1. 打开 **设置 → 应用 → 已安装的应用**
2. 搜索「特能导」
3. 点右侧 `⋯` → **卸载**

### 方式二：通过开始菜单

**开始菜单 → 特能导 → 卸载特能导**

### 方式三：安装目录

进入安装目录（默认 `%LOCALAPPDATA%\Programs\特能导`），运行 `Uninstall 特能导.exe`。

### 卸载时会问你要不要删除数据

卸载程序会弹出询问：

> **是否同时删除「特能导」的历史记录、登录状态与设置数据？**

- 选 **是** → 连同设置、历史、登录状态一并清理干净
- 选 **否**（默认）→ 保留数据，方便以后再装回来继续用

> **注意**：无论选哪个，**已经导出到硬盘上的 PDF / Word / Markdown 文件都不会被删除**。

想彻底清理可以手动删除：

- `%APPDATA%\特能导\`
- `%LOCALAPPDATA%\Programs\特能导\`（若卸载残留）
