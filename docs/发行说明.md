## v1.4.0

> 发布日期：2026-10-30　｜　适用平台：Windows 10 / 11（64 位）

### 本版亮点

- **新增「IMA 知识库」独立功能区**：通过 IMA 官方开放接口整库导出，按目录结构落盘，完整保留多层文件夹、笔记正文与附件。
- **界面按功能拆分**：左侧导航明确区分为「链接导出」与「IMA 知识库」两个独立功能区，各自拥有独立入口、界面与操作流程。
- **应用图标更新**。

### 新增

- **IMA 知识库导出（独立入口）**
  - 流程：配置凭据 → 读取知识库列表 → 选择知识库 → 读取目录树 → 勾选文档 → 导出
  - 输出按 `知识库名/目录层级` 落盘：每篇笔记一个 Markdown，图片自动下载到 `文档名_assets/image-001.png`，附件原样保存（同名自动加 `_2` 序号）
  - 支持「全选 / 全不选」，页面内实时显示导出进度与结果统计
  - 对接 IMA 官方开放接口，需自行到 `ima.qq.com/agent-interface` 申请 Client ID / API Key

### 优化

- 导航重构：原「新建导出」更名为「链接导出」，与「IMA 知识库」清晰隔离，避免功能混淆
- 链接导出页移除 IMA 专属控件，专注网页 / 文档 / 压缩包链接的合并导出

### 下载与安装

1. 下载下方附件 `特能导-1.4.0-安装包.exe`
2. 双击运行，可选择安装目录（支持自定义路径 / 创建桌面与开始菜单快捷方式）
3. 首次运行若出现 Windows SmartScreen 提示，点「更多信息 → 仍要运行」即可（安装包未做代码签名）

**系统要求**：Windows 10 / 11，64 位。

### 升级提示

若你此前安装过更早的预览版本，建议先卸载旧版再安装本版，以避免安装身份冲突。

## 功能总览

| 能力 | 说明 |
| --- | --- |
| 📚 IMA 知识库 | 独立功能区，官方开放接口整库导出，保留目录层级 / 笔记 / 图片 / 附件 |
| 🔗 链接导出 | 粘贴网页、文档、压缩包链接，合并导出为一份干净文档或原文件 |
| 💬 微信公众号 | 标题、公众号名、发布时间、正文排版、图片完整保留，无需登录 |
| 📕 小红书 | 笔记正文 + 图集全部提取 |
| 🧠 知乎 | 问答自动展开全部回答，专栏保留标题层级 |
| 📰 新闻网站 | 澎湃、新华、人民、网易、腾讯、头条、36氪 等 20+ 站点内置识别 |

| 🖥 内置浏览器 | 登录态长期有效，地址栏可搜索，右键一键解析当前页 |
| 📥 资源嗅探 | 抓取页面图片 / 文档 / 压缩包，自动排除视频与音频 |
| 📄 导出格式 | PDF / Markdown / Word / HTML / TXT / JSON / CSV 清单 |
| ⚡ 体验 | 多任务并行、完成提醒、历史记录、任务持久化可重试 |

## 已知限制

- 仅提供 Windows 64 位安装包。
- 安装包未进行代码签名，首次运行可能出现 SmartScreen 提示。
- IMA 知识库导出需自行申请官方开放接口凭据；未配置时不可用（不影响其他功能）。
